## Filtering Lists

As we discussed in the List View page, filtering is possible to sort tickets by the most critical. This can be done easily by clicking on the column names.

Alternatively, we can set arguments to narrow down specific aspects we're looking for. This can be done via the "funnel" button on the top left:

![[Pasted image 20261004093553.png]]

You'll see that we have three arguments here., each of which are on "AND", meaning ALL three conditions must be met:
- STATE IS NEW
- PRIORITY IS 1 - CRITICAL
- ASSIGNMENT GROUP IS SERVICE DESK
