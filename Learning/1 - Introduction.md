**Ticketing** - The system in IT support that's used to track every request or issue that comes in.

Instead of "My printer does not function correctly!", you formally put a ticket forward. A ticket contains things such as:
- A unique ID
- An owner
- A status (Ongoing, Submitted, Completed)
- A timestamp trail

It's important to note that tickets are used to illustrate that issues are indeed getting fixed. Nothing happens informally in a proper environment; if an issue isn't raised via a ticket, it didn't happen. Why? Well, we need tickets for auditing, accountability and knowing who to blame when something goes wrong.

---------

Now, why do we need ticketing?:
- Tracking who reported WHAT, WHEN and WHO'S handling it
- Making sure nothing falls through the cracks and goes unreported
- Measures performance and efficiency in an environment (How fast issues get resolved, workload, etc.)
- Building a knowledge base and ensuring recurring issues can be identified easier, based on prior tickets
