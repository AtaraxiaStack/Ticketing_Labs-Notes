# ServiceNow Checklist

## Setup
- [x] Create developer.servicenow.com account (personal email)
- [x] Request PDI
- [x] Log in regularly so it doesn't hibernate or get reclaimed
- [x] Learn to impersonate a test user and switch back

## Navigation
- [x] Use the filter navigator (type "Incident" and open it)
- [x] List view vs form view
- [x] Filter a list by state, priority and assignment group
- [x] Save a filtered list
- [x] Open a record by number (e.g. INC0010001)

## Working a ticket
- [x] Create an incident (caller, category, short description, description, impact, urgency)
- [x] Assign to a group and to yourself
- [x] Work notes (internal) vs additional comments (user-visible)
- [x] Move through states: New → In Progress → On Hold (with reason) → Resolved
- [x] Add resolution code and close notes
- [x] Reopen a ticket and note why it hurts FCR
- [x] Cancel a duplicate or mistaken ticket

## Core concepts
- [x] Incident vs request (RITM) vs problem vs change
- [x] Priority from impact and urgency (matrix lookup)
- [x] See the SLA timer on a ticket
- [x] Understand pause and breach
- [x] Search the knowledge base
- [x] Attach a KB article to a ticket
- [x] Create a KB article
- [x] Users, groups and roles basics

## Admin basics
- [x] Create a user
- [x] Create a group and add the user
- [x] Create a catalog item (simple request form)
- [x] Create an assignment rule (category → group)

- [ ] Impact vs urgency vs priority
- [ ] What an SLA is, and what pauses it

- [ ] Incident vs request vs problem vs change
