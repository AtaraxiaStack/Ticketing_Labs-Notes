# Ticketing Rundown

## 1. Ticket Types
- [x] **Incident**: something's broken ("can't log in")
- [x] **Request**: standard ask ("new starter needs an account")
- [x] **Problem**: root cause behind repeat incidents
- [x] **Change**: planned modification, needs approval

## 2. Priority & SLAs
- [x] Priority = **impact × urgency** (how many affected, how fast it's needed)
- [x] P1 (critical) to P4 (low) and what each means
- [x] SLA = **response** time vs **resolution** time
- [x] What to do when an SLA is about to breach (escalate, update user, flag it)
- [x] "Pending" pauses the clock, waiting on the user

## 3. Lifecycle
- [x] New → Assigned → In Progress → Pending → Resolved → Closed
- [x] Metrics - How to measure tickets
